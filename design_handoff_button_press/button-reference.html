Button press — design reference

Press with a mouse, a finger, or Enter/Space — one code path, same result. Links wait 240ms so the press is seen before the page turns; a fast tap is held for at least 160ms. The surface travels exactly the height of its drawn side, so the side disappears and the bottom edge never moves.
